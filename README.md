# Earlier Portfolio Website

Static HTML, CSS and JavaScript portfolio with a blog page and browser Snake game.

## Run locally

```sh
python -m http.server 8000
```

Open `http://localhost:8000`. The GitHub Pages source is the `gh-pages` branch. `CNAME` contains the existing custom-domain setting.

## Layout

- `index.html`, `style.css`, `app.js`: portfolio page.
- `BlogPage/`: blog page.
- `Snake/`: browser game.
- `Docs/` and `pics/`: documents and image assets.
